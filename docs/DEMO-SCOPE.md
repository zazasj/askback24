# DEMO-SCOPE — 시연 범위 (G-14)

> 2026-10-25 N1. 화면마다 보이는 링크·버튼·탭을 하나씩 눌러 보고(Playwright 임시 스크립트 `review/tmp/n1-scope.spec.ts`, 커밋 안 함) 누르면 "시연 범위 밖" 알림이 뜨는 것을 모았다. 데스크톱 1440px · 휴대폰 375px, 12개 화면(S1 · S2 · S3 목록·상세 · /about-ai · 404 · S4 1차 ①②③ · S4 최종 ①②③).
> 결과: 알림이 뜨는 컨트롤은 아래 「시연 범위 밖」뿐이고 모두 흐림 표시다. 「동작함」 컨트롤을 눌러서 알림이 뜬 것은 없다.

## 표시 방법

- 한 가지 방식만 쓴다: `v-demo-off`(`src/lib/demoOff.ts`) → `aria-disabled="true"` + 클래스 `is-demo-off` + 설명 연결(`aria-describedby="demo-off-tip"`).
- 글자색은 KRDS gray-50(`--rq-demo-off-text`). 투명도로 흐리지 않는다. 배경색이 있는 버튼은 흰 바탕 + 회색 테두리, 밑줄·화살표·호버 효과는 없앤다.
- 마우스를 올리거나 키보드로 초점이 가면 설명 "시연 범위 밖이에요"가 뜬다(`DemoOffTip.vue`, 화면에 하나). Esc로 닫힌다.
- 누르면 지금처럼 알림(`role=status`)이 뜨고 주소는 그대로다(G-03). 이력서 버튼은 "시연에서는 이력서 출력만 쓸 수 있어요".
- 시연 띠에 "흐린 메뉴는 시연 범위 밖이에요"(G-15).
