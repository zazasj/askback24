## API 명세 대조 결과

`docs/API-SPEC.md`를 `shared/providers/types.ts` · `shared/validate.ts` · `shared/generate.ts`와 줄 단위로 맞춰 봤다. 이 세 파일이 부르는 `remote.ts`와 `api/_lib/*`도 같이 봤다.

**맞는 것**

- 필드 이름: 요청 `items[]` 세 가지, 응답 `questions`/`judgements`, 오류 `{ error: { code, message } }`가 타입과 같다. 값 목록(pref · state · type · origin · tone · topic · review_state)도 같다.
- 필수 여부: `card_id`/`key`와 `text`는 필수다. 판정은 state 3값과 basis가 필수다. evidence와 model은 선택이고, model은 읽지 않는다.
- 호출과 시간 제한: 주소 3개, 머리글, https만, 운영에서 키 필수, 9초에 끊음(`PROVIDER_TIMEOUT_MS`), 다시 부르지 않음, 판정이 시간 초과면 문장 호출 생략이 명세와 같다.
- 실패 처리: 모양이 틀린 문항만 대체하고, HTTP 오류·JSON 아님·바깥 모양 틀림은 그 호출 전체를 대체하며, 오류 본문은 읽지 않는다.
- 검사 목록: 길이 10~260, 인용은 공백을 줄여 비교, 공고에 없는 업무 전제, 금지어 9묶음, 면접관 말 3낱말과 6자 이상 들은 답, basis에 들은 답 통째·금지어가 코드와 같다.

**다른 곳**
